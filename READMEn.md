# 67 Speed — ปลูกป่าไปด้วยกัน

บูธกล้องตั้งโต๊ะสำหรับงานวันวิทยาศาสตร์ ผู้เล่นโยกแขนสองข้างสลับขึ้น-ลงตามท่าไวรัล 67
ให้เร็วที่สุดภายในเวลาที่เลือก ยิ่งทำได้หลายจังหวะ ต้นไม้บนจอยิ่งโตจนกลายเป็นป่า

A camera booth for a school science fair: players do the viral "67" alternating
arm swing as fast as they can, and a tree on screen grows with every rep.
Everything runs in the browser — the video never leaves the machine.

## เปิดใช้งาน / Running it

กล้องทำงานเฉพาะบน secure context เท่านั้น ดับเบิลคลิกไฟล์ตรง ๆ (`file://`) จะเปิดกล้องไม่ได้
ต้องเสิร์ฟผ่าน localhost:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

แล้วเปิด <http://localhost:8000/index.html>

`--bind 127.0.0.1` สำคัญ: ถ้าไม่ใส่ ทุกเครื่องในวง Wi-Fi เดียวกันจะเปิดดูไฟล์ในโฟลเดอร์นี้ได้

## ความยาวรอบ / Round length

เลือกได้ 2 โหมด — **30 วินาที** หรือ **60 วินาที** เปลี่ยนได้ทั้งที่หน้าแรกก่อนเปิดกล้อง
และที่หน้าจอพักก่อนกดเริ่มแต่ละรอบ ค่าที่เลือกถูกจำไว้ข้ามการรีโหลด

กระดานคะแนน **แยกตามความยาวรอบ** เพราะคะแนน 30 วิ กับ 60 วิ ไม่ใช่ความสำเร็จเดียวกัน
ถ้าปนกันสถิติสูงสุดจะไร้ความหมายทันทีที่มีคนสลับโหมด

## ข้อมูล / Data

ทุกอย่างเก็บใน `localStorage` ของเครื่องนั้นเท่านั้น ไม่มีการส่งข้อมูลออกนอกเครื่อง:

| key | เก็บอะไร |
|---|---|
| `t67p_duration` | ความยาวรอบที่เลือกไว้ (30 หรือ 60) |
| `t67p_leaderboard_30` / `_60` | กระดานคะแนนของแต่ละโหมด (สูงสุด 10 อันดับ) |
| `t67p_treesToday` | จำนวนต้นไม้ที่ปลูกสำเร็จ |
| `t67p_communityTotal` | จังหวะรวมของทุกคน |

ล้างกระดานคะแนนก่อนเริ่มงาน — เปิด DevTools Console แล้วรัน:

```js
['t67p_leaderboard_30','t67p_leaderboard_60','t67p_treesToday','t67p_communityTotal'].forEach(k => localStorage.removeItem(k))
```

## การตรวจจับท่า / Pose detection

ใช้ MediaPipe Pose Landmarker (33 keypoints, on-device WASM) โหลดจาก CDN ตอนกดเปิดกล้อง
ระยะทุกค่าในส่วนตรวจจับคิดเป็นสัดส่วนของความยาวลำตัว (ไหล่ถึงสะโพก) เกณฑ์จึงไม่เปลี่ยน
ตามระยะห่างจากกล้อง ค่าที่ปรับได้อยู่ต้นไฟล์ `app.js`:

| ค่า | ความหมาย |
|---|---|
| `SWING_ENTER` | ระยะที่ข้อมือต้องผ่านจุดกลางการโยกถึงจะนับ — นับเองบ่อยให้เพิ่ม, นับยากให้ลด |
| `HANDS_UP_MIN` | ความสูงข้อมือเทียบแนวไหล่ มือห้อยข้างตัวจะไม่นับ |
| `MAX_SWING_MS` | โยกช้ากว่านี้ถือว่าโยกตัวไปมา ไม่ใช่จังหวะ |
| `TREE_STAGE_NEEDS` | จำนวนจังหวะของแต่ละขั้นการโตของต้นไม้ |

**ข้อจำกัดที่รู้อยู่:** เวอร์ชันนี้นับข้อมือสองข้างแยกกัน ยกแขนข้างเดียวโยกรัว ๆ ก็ได้คะแนน
และใช้เกณฑ์ที่ตั้งค่าไว้ตายตัว ไม่ได้วัดสภาพแสงและตัวผู้เล่นจริงก่อนเริ่ม
